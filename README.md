<h2>1. Introducción</h2>

<p>
El Projecte 04 representa la fase final del ciclo formativo SMX2,
donde el alumnado asume un rol técnico dentro de una empresa simulada: EverPia.
</p>

<p>
El proyecto integra conocimientos de sistemas, redes, seguridad, web y sostenibilidad,
simulando un entorno real de consultoría IT.
</p>

<hr>

<h2>2. Objetivo del proyecto</h2>

<ul>
<li>Aplicar conocimientos técnicos en entorno profesional</li>
<li>Gestionar infraestructuras IT reales</li>
<li>Trabajar con metodologías ágiles (Kanban)</li>
<li>Desarrollar documentación técnica completa</li>
<li>Prepararse para el entorno laboral real</li>
</ul>

<hr>

<h2>3. Contexto (EverPia)</h2>

<p>
El alumno forma parte de un equipo junior IT que trabaja en una consultora tecnológica.
Durante el proyecto, se enfrenta a tareas reales como:
</p>

<ul>
<li>Backups y recuperación</li>
<li>Servidores Linux</li>
<li>Acceso remoto</li>
<li>Diseño web en Figma</li>
<li>Gestión de proyectos con GitHub</li>
</ul>

<hr>

<h2>4. Metodología</h2>

<ul>
<li>Kanban mediante Microsoft Planner</li>
<li>Trabajo individual y en equipo</li>
<li>Control de versiones con GitHub</li>
<li>Documentación técnica continua</li>
</ul>
